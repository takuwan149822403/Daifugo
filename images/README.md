# 画像素材

ゲームは分割済みPNGを読み込み、表示サイズに合わせて拡縮します。実行時のアトラス分割はありません。

| フォルダ | 内容 | サイズ（幅×高さ） |
| --- | --- | --- |
| `cards/` | `spades_01.png`〜`spades_13.png`、`hearts_01.png`〜`hearts_13.png`、`diamonds_01.png`〜`diamonds_13.png`、`clubs_01.png`〜`clubs_13.png` | 130×149 |
| `cards/` | `back.png`（裏面） | 130×148 |
| `portraits/` | `npc_01.png`〜`npc_12.png` | 340×332 |
| `buttons/` | `start.png`、`quit.png`、`back.png`、`confirm.png`、`rules.png` | 967×237 |
| `old/` | 分割前の元画像3点 | 元のまま |

カードの番号は01=A、02〜10=数字、11=J、12=Q、13=Kです。スートはスペード、ハート、ダイヤ、クラブの順で、元の透過情報を保持しています。ジョーカー2枚はゲーム側で描画します。

NPCの番号は元画像の左上から右へ、次に下の行へ進む順です。ゲームでは従来どおり01〜03の3人を表示します。背景などの単体画像はこのフォルダ直下に置いています。
